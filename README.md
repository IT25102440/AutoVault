## 📂 OOP Concepts

| Concept | Implementation |
|---------|----------------|
| Encapsulation | All entity fields private, access via getters/setters |
| Inheritance | `User` (abstract) → `Seller`, `Admin` |
| Polymorphism | `getDashboard()` method overridden in `Seller` and `Admin` |
| Abstraction | Abstract `User` class, Repository interfaces, Service layer |
| Information Hiding | Strict layer separation, passwords never exposed in API |
