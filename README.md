# 🏎️ AutoVault: Second-Hand Car Platform
SE1020 OOP Project - Second Hand Car Sales Platform

A structured marketplace for buying and selling second-hand vehicles, built to demonstrate core **Object-Oriented Programming (OOP)** principles.

---

## 🛠️ Project Status: In Development
This project is currently under active development as part of the **SE1020 - Object Oriented Programming** module.

- [x] Initial Spring Boot 3.5.1 Setup
- [x] Database Schema Design (MySQL)
- [x] GitHub Repository & Team Integration
- [ ] Core Model Layer (Abstract Classes & Inheritance)
- [ ] User Authentication & Role-Based Access
- [ ] Car Listing CRUD Operations

---

## 🚀 Technology Stack
* **Backend:** Java 17, Spring Boot 3.5.1
* **Database:** MySQL 8.x, Spring Data JPA
* **Security:** Spring Security
* **Frontend:** HTML5, Bootstrap 5, Vanilla JavaScript
* **Utilities:** Lombok

---

## 📂 Core Architecture
This project implements the following OOP concepts to meet academic criteria:
- **Abstraction:** Centralized logic in the `User` abstract class.
- **Inheritance:** Specialized `Seller` and `Admin` roles.
- **Encapsulation:** Secure data handling via private fields and JPA.
- **File Handling:** Server-side image storage for vehicle listings.

## 🔧 Setup & Installation
1. Clone the repository: `git clone <repo-url>`
2. Configure your MySQL credentials in `src/main/resources/application.properties`.
3. Create a database named `carplatform`.
4. Run the application via your preferred IDE.
